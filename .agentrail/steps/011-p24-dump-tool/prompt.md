Create a p24-dump Rust CLI tool that pretty-prints .p24 and .p24m file layouts. For .p24 v1/v2: show header fields (magic, version, entry_point, code_size, data_size, global_count), export table (name, offset), import table (unit, name, slot). For .p24m: show header (entry_point, unit_count, total_code, total_globals, offsets), unit table (base_addr, global_base, irt_off per unit), IRT entries per unit, code/data/globals region sizes. Hex dump of code with basic disassembly (opcode names + operands). Can add to loader/ crate as a second binary or as a new crate. Usage: p24-dump file.p24 or p24-dump file.p24m.
