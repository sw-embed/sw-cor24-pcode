Created p24-load Rust binary crate (loader/) that reads multiple v2 .p24 files and produces .p24m multi-unit images. Implements: v2 header parsing, sequential code layout, global partitioning, import-to-export resolution by name, IRT construction with absolute addresses, LOADG/STOREG/ADDRG operand patching, .p24m emission with unit table + IRTs + code/data/globals. Includes parse_p24m() for verification. 10 tests cover two-unit linking, IRT resolution, global patching, error cases, round-trip, v1 compat. Added Debug derive to pa24r::LoadedImage.
