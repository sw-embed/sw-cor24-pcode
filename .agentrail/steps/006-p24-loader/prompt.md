Create a new Rust binary crate loader/ in the workspace. The loader (p24-load) reads multiple v2 .p24 files and produces a .p24m multi-unit image. Implementation: (1) parse v2 .p24 headers including export/import tables, (2) assign unit IDs (0..N-1) in CLI order, first file is entry unit, (3) layout code segments sequentially assigning base addresses, (4) layout global segments with per-unit partitions, (5) resolve imports against exports using name hashes with string-table collision detection, (6) build IRT (import resolution table) with absolute 3-byte addresses, (7) build unit table (base_addr + global_base per unit), (8) patch LOADG/STOREG/ADDRG operands with global partition offsets, (9) emit .p24m format per docs/load-time-resolution.md section 6. Error on unresolved imports, hash collisions, duplicate unit names, address overflow. Test: two synthetic .p24 units, verify image layout and IRT correctness.
