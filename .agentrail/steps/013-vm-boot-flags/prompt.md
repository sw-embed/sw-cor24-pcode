Add a vm_flags byte to pvm.s at a patchable address (like code_ptr). Flags control VM behavior at boot: bit 0 = verbose boot (print memory map: code base, globals base, stack sizes, unit count, IRT info). bit 1 = trace mode (print each opcode as it executes — useful for debugging). Set via --patch on the cor24-run command line. Update _start to check flags after .p24m/.p24 detection and print diagnostics. Document the flag byte address in a comment.
